# React Native Password Generator

A simple and secure **Password Generator** app built with **React Native**. Generate strong, random passwords with customizable options for length, characters, and symbols, right from your mobile device.

## Features

- Generate random passwords instantly
- Customize password length
- Include/exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Copy passwords to clipboard with a single tap
- User-friendly interface
